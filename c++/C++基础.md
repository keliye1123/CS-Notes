## 一、C/C++编译过程
编译过程一共分为：预处理->编译->汇编->链接，共四步，我将用命令行操作来详细分析过程。

### 1.预处理过程
- 命令
~~~ 
g++ -E main.cpp -o main.i
~~~
- 作用
  - 去掉注释
  - 预处理指令替换
  - 头文件替换
  - 生成.i文件

- 具体过程

~~~ cpp
//这是演示源码
#include <iostream>

#define MAXSIZE 100

#ifndef DEMO
    #define DEMO std::cout << "this is demo" << std::endl;
#endif

//这是一个demo
int main(){
    int a[MAXSIZE]= {};
    DEMO
    return 0;
}    
~~~

- 代码执行结果
![image1.png](Image/c++/C++基础/C++基础_image1.png)

- 结果解释
预处理完的.i文件和源文件十分相似，不同的是.i文件将"//这是演示源码"等注释去除
执行了"#ifndef #endif"命令,我们可以看到我们写的代码从原来的第十几行的位置变成了
第三万多行，这是应为预处理把"#include <iostream>"这个头文件替换成了头文件的源代码。

### 2.编译阶段
- 命令
~~~
g++ -S main.i -o main.s
~~~

- 作用
  - 检查代码报错
  - 将C/C++语言翻译成汇编语言
  - 生成.s文件

- 具体演示
  - 执行结果（生成汇编代码）
  - ![image1.png](Image/c++/C++基础/C++基础_image2.png)
  - 检查错误代码验证
  - ![image1.png](Image/c++/C++基础/C++基础_image3.png)
  - 错误代码执行结果
  - ![image1.png](Image/c++/C++基础/C++基础_image4.png)

- 结果解释
在执行预处理命令时编译器没有报错，在执行编译命令是报错说   
明检查代码错误是在编译阶段进行的。

### 3.汇编阶段
- 命令
~~~
g++ -c main.s -o main.o
~~~
- 作用
将.s文件汇编成二进制文件即.o文件

### 4.链接阶段
- 命令
~~~ cpp
g++ main.o -o mains
~~~
- 作用
连接产生.exe文件这是最简单的链接操作，只链接了我们写的mian.o和隐式链接了C++中一些标准头文件
例如<iostream>,链接过程和动态库和静态库密切相关，这里只简单讲。

## 二、动态库与静态库
我们在网上下载的各种工具包本质就是一个个静态库或是动态库，了解动态库和静态库的工作
原理能更好懂得如何配置不同的库。

### 1.静态库
- 特征
.o（Linux）或者.lib（windows）的文件
- 性质
由多个.o归档打包而成，链接时嵌入.exe文件中
 - 优点：不用外部依赖.o或者.lib文件
 - 缺点：当包更新时，需要重新编译链接包费时不灵活，且嵌入.exe文件中是其变臃肿。
