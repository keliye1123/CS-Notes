## 一、线程概述
线程是轻量级的进程(LWP：light weight process)，在Linux环境下线程的本质仍是进程。在计算机上运行的程序是一组指令及指令参数的组合，指令按照既定的逻辑控制计算机运行。操作系统会以进程为单位，分配系统资源，可以这样理解，进程是资源分配的最小单位，线程是操作系统调度执行的最小单位。
- 先从概念上了解一下线程和进程之间的区别：
    - 进程有自己独立的地址空间，多个线程共用同一个地址空间
        - 线程更加节省系统资源，效率不仅可以保持的，而且能够更高
        - 在一个地址空间中多个线程独享：每个线程都有属于自己的栈区（创建的局部变量和创建的指针本身是独享的），寄存器(内核中管理的)
        - 在一个地址空间中多个线程共享：代码段，堆区，全局数据区（全局变量，静态变量和指针指向的内存地址是共享的），打开的文件(文件描述符表)都是线程共享的
    - 线程是程序的最小执行单位，进程是操作系统中最小的资源分配单位
        -  每个进程对应一个虚拟地址空间，一个进程只能抢一个CPU时间片
        - 一个地址空间中可以划分出多个线程，在有效的资源基础上，能够抢更多的CPU时间片  
          ![多线程编程_image1](Image/c++/多线程编程/多线程编程_image1.png)
    - CPU 的调度和切换：线程的上下文切换比进程要快的多（因为线程没执行完会把上下文存在寄存器中）
        - 上下文切换：进程/线程分时复用CPU时间片，在切换之前会将上一个任务的状态进行保存，下次切换回这个任务的时候，加载这个状态继续运行，任务从保存到再次加载这个过程就是一次上下文切换。
    - 线程更加廉价，启动速度更快，退出也快，对系统资源的冲击小。


## 二、c++11多线程编程

### 创建线程
std::thread：线程实例
```cpp
//1.创建线程,第一个参数为函数，剩下的参数为函数的传入参数
std::thread thread1 (函数,...);
//如果函数是静态类函数与上面一样，如果不是静态类函数则要加上类的实例
std::thread thread1 (&类名::类中的函数名,类的实例名,...);
```
- join():阻塞主线程等待子线程结束
- detach()：将子线程与主线程分离
- joinable()：判断当前线程实例能否使用join()或者detach()
```cpp
//1.创建线程
    std::thread thread1 (Add_,1,2,3);
    std::thread thread2 (Mul_,1,2);

    //判断当前线程能否使用join或者detach
    //不能被join或者detach的情况1.已经被join或者detach过了
    //2.线程为空，3.线程对象被move过
    bool is_join = thread1.joinable();
    if (is_join) {
        //该线程未执行完则当前进程阻塞，等待该线程执行完
        thread1.join();
    }
    //将该线程与当前线程分离分离，当前线程结束，该线程可以继续在后台运行
    thread2.detach();
```

### 数据未定义错误
当给thread传入参数时，只有形参用int&修饰还不够，实参要用std::ref()修饰，才能进行址传递或者使用int*也可以实现址传递,如果指针在子线程运行时被销毁则会报错。  
```cpp
#include <iostream>
#include <unistd.h>
#include <thread>

void Add_(int& a,int* b,int& c) {
    a = a + 1;
    b = b + 1;
   std::cout << a+b+c << std::endl;
}

int main() {
    //1.创建线程
    int a=  1,c = 3;
    int* b = new int(2);
    std::thread thread1 (Add_,std::ref(a),b,std::ref(a));
    bool is_join = thread1.joinable();
    if (is_join) {
        thread1.join();
    }
    std::cout << a << std::endl;
    std::cout << b << std::endl;
    delete(b);//只能在join后面delete
}
```  

### 互斥量解决多线程数据共享问题
- 互斥锁 std::mutex mtx;
- 上锁：mtx.lock();
- 解锁：mtx.unlock();
- 线程安全：如果多线程程序每一次的运行结果和单线程运行的结果始终是一样的那么你的线程就是安全的。
```cpp
#include <iostream>
#include <unistd.h>
#include <thread>
#include <mutex>

int A = 0;
std::mutex mtx; //声明互斥锁
void Func_() {
   for (int i = 0;i < 10000000;i++) {
       //在互斥锁中间的值在运行加一操作时不能被其他线程修改
       mtx.lock();//获得所有权
        A += 1;
       mtx.unlock();//释放所有权
   }
}

int main() {
    //1.创建线程
    std::thread thread1 (Func_);
    std::thread thread2 (Func_);

    thread1.join();
    thread2.join();

    std::cout << A << std::endl;
    return 0;
}
```

### 互斥量死锁
- 当thread1获得m1的所有权thread2获得m2的所有权时，thread1要等到得到m2的所有权thread2要等待获得m1的所有权，就会发生死锁。  
```cpp
#include <iostream>
#include <unistd.h>
#include <thread>
#include <mutex>

int A = 0;
std::mutex m1,m2; //声明互斥锁
void Func1_() {
    for (int i = 0; i < 100; i++) {
        m1.lock();
        m2.lock();
        m1.unlock();
        m2.unlock();
    }
}

void Func2_() {
    for (int i = 0; i < 100; i++) {
        m2.lock();
        m1.lock();
        m1.unlock();
        m2.unlock();
    }
}

int main() {
    //1.创建线程
    std::thread thread1 (Func1_);
    std::thread thread2 (Func2_);

    thread1.join();
    thread2.join();

    std::cout << A << std::endl;
    return 0;
}
```

### lock_guard与c++11std::unique_lock

#### 1.lock_guard
- std::lock_guard 是C++ 标准库中的一种互斥量封装类，用于保护共享数据，防止多个线程同时访问同一资源而导致的数据竞争问题。
- std::lock_guard 的特点如下：
    - 当构造函数被调用时，该互斥量会被自动锁定。
    - 当析构函数被调用时，该互斥量会被自动解锁。
    - std::lock_guard 对象不能复制或移动，因此它只能在局部作用域中使用。  
```cpp
#include <iostream>
#include <unistd.h>
#include <thread>
#include <mutex>

int shared_data = 0;
std::mutex m1; //声明互斥锁
void Func_() {
    for (int i = 0; i < 5; i++) {
        std::lock_guard<std::mutex> lg(m1);//在for循环作用域内会上锁，出了作用域调用析构函数解锁。
    }
}


int main() {
    //1.创建线程
    std::thread thread1 (Func_);
    std::thread thread2 (Func_);

    thread1.join();
    thread2.join();
    std::cout << shared_data << std::endl;
    return 0;
}
```

#### 2.std::unique_lock
- std：:unique_lock 是C++标准库中提供的一个互斥量封装类，用于在多线程程序中对互斥量进行加锁和解锁操作。它的主要特点是可以对互斥量进行更加灵活的管理，包括延迟加锁、条件变量、超时等。
- std::unique_lock 提供了以下几个成员函数：
    - 1ock()：尝试对互斥量进行加锁操作，如果当前互斥量已经被其他线程持有，则当前线程会被阻塞，直到互斥量被成功加锁。
    - try_1ock()：尝试对互斥量进行加锁操作，如果当前互斥量已经被其他线程持有，则函数立即返回false，否则返回true。
    - try_lock_for(const std::chrono::duration<Rep, Period>& rel_time): 尝试对互斥量进行加锁操作，如果当前互斥量已经被其他线程持有，则当前线程会被阻塞，直到互斥量被成功加锁，或者超过了指定的时间。
    - try_lock_until(const std::chrono::time_point<Clock, Duration>& abs_time)：尝试对互斥量进行加锁操作，如果当前互斥量已经被其他线程持有，则当前线程会被阻塞，直到互斥量被成功加锁，或者超过了指定的时间点。（比较少用）
    - unlock()：对互斥量进行解锁操作。
```cpp
#include <iostream>
#include <unistd.h>
#include <thread>
#include <mutex>

int shared_data = 0;
std::timed_mutex m1; //声明互斥锁
void Func_() {
    for (int i = 0; i < 5; i++) {
        std::unique_lock<std::timed_mutex> lg(m1,std::defer_lock);//第二个参数std::defer_lock的作用是构造但不自动加锁，自己手动加锁，传入第二个参数就自动加锁
        if (lg.try_lock_for(std::chrono::seconds(2))) {//等待两秒，如果2秒后还没获得所有权就返回false
            std::this_thread::sleep_for(std::chrono::seconds(1));//线程休息1秒
            shared_data++;
        }
    }
}


int main() {
    //1.创建线程
    std::thread thread1 (Func_);
    std::thread thread2 (Func_);

    thread1.join();
    thread2.join();
    std::cout << shared_data << std::endl;
    return 0;
}
```

### call_once的使用
- call_once(std::once_flag,函数)：保证多个线程调用同一个函数时，函数总共只能被调用一次。
- call_once只能在线程中被调用，不能在main中调用。
```cpp
#include <iostream>
#include <unistd.h>
#include <thread>
#include <mutex>

static int* log = nullptr;
std::once_flag flag;

void init_() {
    log = new int;
    std::cout << 1 << std::endl;
}

void test() {
    // init_();
    std::call_once(flag, init_);//保证init只被调用一次
}

int main() {
    //1.创建线程
    std::thread thread1 (test);
    std::thread thread2 (test);
    std::thread thread3 (test);

    thread1.join();
    thread2.join();
    thread3.join();
    return 0;
}
```


### std::condition_variable的使用
std::condition_variable（条件变量）用于线程等待某个条件成立，实现线程间同步，常搭配 std::mutex + std::unique_lock。
- wait(lk):释放锁，阻塞等待；被唤醒后重新获取锁
- wait(lk, pred):带判断条件，防止虚假唤醒
- notify_one():唤醒任意一个等待中的线程
- notify_all():唤醒全部等待中的线程
- wait_for / wait_until:限时等待（超时自动返回）
```cpp
#include <iostream>
#include <unistd.h>
#include <thread>
#include <mutex>
#include <condition_variable>
#include <queue>

std::queue<int> que;
std::condition_variable cv;
std::mutex mtx;

void producer() {
    for (int i = 0;i < 10;i++) {
        std::unique_lock<std::mutex> lock(mtx);
        //加的时候要通知消费者
        que.push(i);
        std::cout << "producer: " << i << std::endl;
        //唤醒wait函数
        cv.notify_one();
    }
    std::this_thread::sleep_for(std::chrono::milliseconds(500));
   }

void consumer() {
    for (int i = 0;i < 10;i++) {
        std::unique_lock<std::mutex> lock(mtx);
        //如果队列为空时wait阻塞等待,释放锁
        cv.wait(lock,[](){return !que.empty();});
        //执行 wait 瞬间，如果条件为false会自动调用 lock.unlock()，把 mtx 交出去。目的：让生产者线程能够拿到锁、往队列里塞数据。
        //直到producer执行notify_one，wait会继续判断条件，如果为false继续unlock()休眠,如果为true就往下运行。
        int val = que.front();
        que.pop();
        std::cout << "consumer: " << val << std::endl;
    }
}

int main() {
    //1.创建线程
    std::thread t1 (producer);
    std::thread t2 (consumer);

    t1.join();
    t2.join();
    return 0;
}
```

### 原子操作
原子变量自动管理数据共享问题，不用加锁,且效率更高
```cpp
#include <iostream>
#include <unistd.h>
#include <thread>
#include <mutex>
#include <condition_variable>
#include <queue>
#include <atomic>

std::atomic<int> share_data;

void func() {
    for (int i = 0; i < 1000000; i++) {
        ++share_data;
    }
}
int main() {
    //1.创建线程
    std::thread t1(func);
    std::thread t2(func);
    t1.join();
    t2.join();
    std::cout << share_data << std::endl;
    return 0;
}
```

### 线程池
```cpp
#include<iostream>
#include<thread>
#include <mutex>
#include <queue>
#include <string>
#include <condition_variable>
#include <vector>
#include <functional>

class ThreadPoll {
    //属性
private:
    std::vector<std::thread> threads;       //线程数组
    std::queue<std::function<void()>> tasks;//任务队列

    std::mutex mtx;
    std::condition_variable cv;

    bool stop;  //显示线程池什么时候终止

    //方法
public:
    ThreadPoll(int ThreadNum) {
        stop = false;
        for (int i=0; i<ThreadNum; i++) {
            threads.emplace_back([this] {
                while (true) {
                    std::unique_lock<std::mutex> lock(mtx);
                    cv.wait(lock, [this] {
                        return !tasks.empty() || stop;
                    });

                    if (stop && tasks.empty()) return;

                    std::function<void()> task(std::move(tasks.front()));
                    tasks.pop();
                    lock.unlock();
                    task();
                    // todo;
                    //unlcok放在task的前和后都不会抢占tasks工作队列，但放在task前会导致线程抢占io资源

                }
            } );
        }
    };

    ~ThreadPoll() {
        {
            std::unique_lock<std::mutex> lock(mtx);
            stop = true;
        }

        cv.notify_all();
        for (auto& t : threads) {
            t.join();
        }
    }

    template<typename T,typename... Args>
    void enqueue(T &&t, Args&&... args) {
        //bind的作用：把函数封装成一个不用输入参数的对象
        // void foo(int a,int b){}
        // auto func = std::bind(foo,10,20);
        // func(); //等价foo(10,20)
        //std::forward的作用：
        std::function<void()> task = std::bind(std::forward<T>(t),std::forward<Args>(args)...);

        {//限定锁的范围
            std::unique_lock<std::mutex> lock(mtx);
            tasks.emplace(std::move(task));
        }

        cv.notify_one();

    }

    
};

int main() {
    ThreadPoll pool(4);
    for (int i=0; i<10; i++) {
        pool.enqueue([i] {
            printf("task:%d IS RUN\n",i);
            printf("task:%d IS SLEEP\n",i);
            // std::cout <<"task:"<< i <<" IS RUN"<< std::endl;
            // std::this_thread::sleep_for(std::chrono::seconds(1));
            // std::cout <<"task:"<< i <<" IS SLEEP"<< std::endl;
        });
    }
}
```
